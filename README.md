# Safetics — бекенд

Spring Boot 4.1, Java 21, PostgreSQL 17, Flyway. Модульний моноліт.

## Що потрібно

- JDK 21
- Maven 3.9+ (або вбудований у IntelliJ)
- Docker Desktop (для локальної бази і для тестів через Testcontainers)

## Запуск

```bash
docker compose up -d          # PostgreSQL на localhost:5433
mvn spring-boot:run           # Flyway накатить міграції, застосунок стартує на :8080
curl localhost:8080/actuator/health
```

## Тести

```bash
mvn test
```

`TenantIsolationTest` піднімає окремий PostgreSQL у Docker і перевіряє, що компанія A не бачить і не змінює дані компанії B.

## Як влаштована мультитенантність

- Кожна таблиця компанії має `company_id` і політику Row-Level Security (`V3__row_level_security.sql`).
- Дві ролі в базі:
  - `safetics_owner` — власник схеми, під ним працює лише Flyway;
  - `safetics_app` — застосунок, без `SUPERUSER` і `BYPASSRLS`. Цю роль створює міграція `V1`.
- `TenantContext` зберігає поточну компанію і користувача для потоку.
- `TenantAwareDataSource` при кожному отриманні з'єднання з пулу пише їх у сесію PostgreSQL (`app.company_id`, `app.user_id`). Без контексту RLS не віддає жодного рядка.
- Наступний крок: JWT-фільтр, який заповнює `TenantContext` з токена.

## Структура пакетів (план)

```
com.safetics
├── core        компанії, користувачі, ролі, дозволи, tenancy, журнал змін
├── assets      типи об'єктів і об'єкти (свердловини, установки)
├── projects    контракти, ставки
├── reports     змінні рапорти, інтервали, журнал операцій, затвердження
├── stock       склади, рухи, прогноз запасів
├── hse         чек-листи, інциденти, розслідування
└── billing     місячні рахунки
```

## Правила, закладені з першого дня

- Гроші зберігаються цілими числами в мінімальних одиницях валюти.
- Рухи складу не змінюються, помилки виправляються лише сторнуванням.
- Ціна копіюється в наряд у момент його створення.
- У коді перевіряється лише дозвіл (`stock.write_off`), ніколи назва ролі.
- Затверджений рапорт заблокований, зміни вносяться лише коригувальним записом.
- Журнал змін (`audit_log`) — лише додавання.
